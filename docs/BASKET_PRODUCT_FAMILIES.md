## Cell-level contract for the principal monthly artifact

`scripts/basket_lineage_report.py` deterministically assigns each CBA and CBT cell using declared boundaries: `imputed` before 2016-04, `derived` from 2016-04 through 2025-07, and `synthetic` from 2025-08. `derived` means source-derived after price transformation, not directly observed. Because raw sources and run metadata were not retained, source observation IDs are unresolved and no committed principal cell can honestly be labelled `observed`.

The canonical status vocabulary is `observed`, `derived`, `imputed`, `interpolated`, `projected`, `synthetic`, and `unresolved`. Fixture releases carry status, source observation ID, transformation chain, monetary reference, method version, and warnings on every individual measure cell. The real snapshot exposes the same classification reproducibly as a report rather than duplicating more than 3,000 values.
